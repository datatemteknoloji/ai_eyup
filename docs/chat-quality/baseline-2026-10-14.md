### Güçlü yanlar (korunacak)

- Kod/durum anlamı: OpenShift 7/7, Sanallaştırma 2/2, Admin 2/2 (exit code 137/143, CrashLoopBackOff, ImagePullBackOff, Degraded… doğru anlam). Burada model bilgisine güvenilebiliyor; yine de sözlük (O4/V5) ileride doğrulamayı koda taşıyacak.
- OpenShift "neden" soruları araç çağırıyor (log/event/pod araçları); gözlem-yorum ayrımı manuel listede.
- Küçük deterministik cevaplar (`db_fast_path`) çoğu sayım sorusunda <1 sn.

## 4. Yöntem ve sınırlar

- **Gerçek uç noktalar, gerçek saat.** Dondurulmuş saat (`now_override`) bu üç sohbette yok; zaman soruları (`dün`, `geçen hafta`) bu yüzden manuel.
- **Gerçek değer:** `truth.py` DB'den salt-okunur SELECT ile hesaplar; sabit sayı yok. Güç durumu sınıflandırması tek yerde (`POWER_ON/OFF`: `Running`, `Stopped`, `POWERED_ON`, `poweredOn`…).
- **Araç izi:** yalnızca OpenShift ve Admin akışları `tool_call` olayı yayınlıyor; Sanallaştırma `/ask/stream` yayınlamıyor (bu yüzden virt'te araç kuralı kullanılmadı). Faz 2 doğrulayıcısı için ek bir (opt-in) iz gerekecek.
- **Maskeleme / gizli bilgi soruları** (`sec`): gerçek cluster'dan Secret çektiği için varsayılan olarak çalışmaz (`--include-secrets`). Baseline'a dahil değil; Faz 1.5 öncesi ayrıca ölçülecek.
- **Enjeksiyon (veri kaynaklı):** log/YAML/VM notuna kasıtlı satır yerleştirmek uygulama verisini değiştireceği için yapılmadı; yalnızca kullanıcı girdisi enjeksiyonu ölçüldü.
- **RBAC:** Faz 0 yalnızca `admin` ile ölçtü; kısıtlı kullanıcı testi Faz 5 (A7) ile eklenecek.
- **Otomatik kural sınırları:** Türkçe sayı sözcüğü yalnızca "iki adet" gibi birim ile; "evrende olmayan varlık" kuralı yalnızca bilinen ad ailelerini (sahte VM/host/node adı kalıpları) denetler.

## 5. Çalıştırma

```bash
python scripts/chat_bench/run.py --list                       # soru listesi
python scripts/chat_bench/run.py --module all --set smoke     # hızlı doğrulama (32 soru)
python scripts/chat_bench/run.py --module all --set all --tag after-faz1
python scripts/chat_bench/run.py --module ocp --set cnt,prem  # kategori
python scripts/chat_bench/run.py --module all --rescore 'docs/chat-quality/baseline/baseline-{module}.json' --tag rescore
```

- Üç modülü **paralel** çalıştırmayın: LLM kuyruğu dolar ve altyapı hatası üretir (ilk koşuda olduğu gibi). Modülleri sırayla çalıştırın.
- Altyapı hatalı soruları yeniden çalıştırmak için `--resume <önceki json>`.
- Bench oturum açar, sorduğu sohbet oturumlarını sonunda siler (token süresi dolsa bile yeniden giriş yapar).
