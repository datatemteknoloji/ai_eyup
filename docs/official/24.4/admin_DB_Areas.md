# Database Areas

Broadcom recently implemented an agentic AI search tool on techdocs.broadcom.com. To help you navigate the search tool and improve your search experience, we recommend the following best practices when entering your search request:

This topic describes the available database areas and lists only the main table for each area. For a complete list of the tables, see the DB Schema in the Reference Guides section of the Automic Automation documentation at Broadcom TechDocs.

The size of this area depends on the number of objects that have been created. Usually, it grows slowly.

If the Version Management is used or Transport Cases are loaded and Clients are copied, these tables grow rapidly. Use the provided utilities for deleting object versions, Recycle Bin contents, or Clients that are no longer used.
