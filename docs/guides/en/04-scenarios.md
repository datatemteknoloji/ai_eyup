## 13. End-to-End Scenarios

**vCenter:** Integrations → test → sync → virt dashboard / reports → `/virt/chat`.

**Linux:** SSH credentials → host → exporter → `/metrics` or `/linux/chat`. Patching on Packages / System update. LVM: Level 1.

**OpenShift:** Integrations → OpenShift → command centre → `/openshift/chat`. KubeVirt: `/openshift/vms`.

**oVirt / OLVM:** Integrations → type kvm → sync → virt menus + `/virt/chat`.

**Prometheus:** PromQL in chat only. Job names in Settings → Monitoring.

**Level 1:** `/level1` → mapped server → wizard → Request → Preview → Apply → jobs.
