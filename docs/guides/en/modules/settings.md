# ainew — Settings & administration GUIDE

Settings `/settings`, users `/users`, audit `/audit`. Most tabs are admin-only.

| Tab | Actions |
|-----|---------|
| Linux SSH | Identities, default, apply |
| WinRM | Windows identities |
| AI | Ollama / `REMOTE_LLM_*` |
| Branding | Application name, logo, company name, login tagline, login headline and description, and footer text (shown on the login page) |
| RAG | Runbook / incident / metric embeddings |
| Monitoring | Prom / Pushgateway, job names |
| Security | Session, policy, AD and SSO (OIDC: issuer, client ID/secret, group→role mapping, "Test configuration") |
| Advanced | Retention, chat/LLM/RAG gates and timings (answer cache, progress indicator, entity/count gates, grounding mode, LLM timeouts, RAG relevance threshold), worker counts |
| About | Version and **product GUIDE PDFs** |
| Platform / backup / update / danger | Operations |

Users: role + **module checkboxes**. Audit: `/audit` (ainew) and `/level1/audit` (Level 1 admin). GUIDE downloads: TR/EN, full or module packs — not a live VM list.
