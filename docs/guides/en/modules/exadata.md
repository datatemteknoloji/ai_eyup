# ainew — Exadata GUIDE

Module `exadata`: Oracle Exadata racks, compute nodes, storage cells, reports, AIOps.

| Menu | Path | Actions |
|------|------|---------|
| Inventory | `/exadata` | Rack / node / cell |
| Reports | `/exadata/reports` | Infra reports |
| AIOps | `/exadata/chat` … `/analysis` | Assistant and ops |

Connect at `/integrations/exadata`. Not a substitute for Linux SSH or Level 1 ASM wizards (those target a Linux host).
